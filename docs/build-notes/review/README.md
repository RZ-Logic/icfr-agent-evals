# Review records

These three JSON files are the raw machine records of the AI-assisted first build and its review, kept unedited as evidence; [`../FIRST-BUILD-REPORT.md`](../FIRST-BUILD-REPORT.md) summarizes them. `BUILD-AGENT-RESULTS.json` holds the build steps' own reports, which pre-registration exception (i) rests on; `FINDERS-RAW.json` and `VERIFIERS-AND-SCORER.json` hold the findings, reproductions and verdicts behind the finding ids that the regression tests name.
The file paths inside them are paths in the build container and name no person.
