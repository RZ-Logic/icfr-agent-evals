## How the report was produced

Both commands read the logs, make no model call and need no API key.

Before the second freeze, `scripts/run_report.py` prints counts over all logs together only. After it, the unseal step runs the same report with the sealed grading results added:

```
python scripts/unseal_report.py --sealed-dir <grading root>/_sealed \
  --worker haiku55=<log> --worker sonnet55=<log> --worker opus55=<log> --worker sonnet5=<log> \
  --template <template log> --packet-dir runs/reviews/eval-2026-11-21 \
  --second-look-dir <second-look folder> --blind-check-dir <blinding-check folder> \
  --first-archive <url> --first-archive-date <date> --second-archive <url> --second-archive-date <date> \
  --json <report.json>
```

The unseal step refuses unless both freeze checks pass. The grading evidence must name exactly the frozen manifest's worker logs. Every sealed file must match its recorded SHA-256. The committed code must recompute the gate, the breaker, the means and the queue byte for byte (decision D-R23, unseal step).
